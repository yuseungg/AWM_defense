# ASSET_GUIDE.md — AI 에셋 스타일 기준

> **목적: B 부재(D6~D7) 중에도 폰에서 같은 스타일의 PNG가 나오게 한다.**
> 이 문서만 보고 프롬프트를 채워 넣으면 기준을 다시 물어볼 필요가 없어야 한다.
> 파이프라인은 이미 동작한다(`vite.config.js` `publicDir` + `GameScene.preload()` +
> `TowerView`/`EnemyView`의 `textures.exists()` 폴백) — **PNG 파일만 아래 경로에 넣으면
> 코드 변경 없이 반영된다.**

---

## 1. 아트 방향 (P0 확정, 바꾸지 않는다)

**추상 맵 — 단색 실루엣 + 단일 액센트 컬러.**

- 배경·경로·격자는 전부 무채색에 가까운 어두운 톤(`UITheme.js`의 `COLOR.bg`/`COLOR.path`)이다.
- 그 위에 서는 오브젝트(타워·적·서포터·장애물)는 **각자 하나의 고유색으로 채워진 평면 실루엣**이다.
  그라디언트·텍스처·그림자·입체감 없음 — 아이콘에 가깝다.
- UI 전체를 관통하는 **단일 액센트 컬러**는 청록 계열(`COLOR.accent`, `#3fa7d6`)이다. 경로 선·
  사거리 원·버튼 테두리가 전부 이 색이다. **오브젝트 실루엣 색은 액센트와 겹치지 않게** 고른다
  (청계천만 예외 — 물이라는 소재 자체가 액센트와 같은 청록이라 의도적으로 맞췄다).
- 실사·3D 렌더링·복잡한 디테일 금지. **윤곽만 보고 뭔지 알아볼 수 있어야 한다** — 이게 §3의
  핵심 규칙이다.

## 2. 색상 팔레트

### 2-1. 전역(참고용 — 오브젝트에는 안 씀)

| 이름 | hex | 용도 |
|---|---|---|
| `COLOR.bg` | `#11141a` | 맵 배경 |
| `COLOR.path` | `#2a3040` | 경로 |
| `COLOR.accent` | `#3fa7d6` | UI 전역 액센트(사거리 원·경로 선 등) |

### 2-2. 오브젝트 기준색 — 14종

랜드마크 6종·적 4종의 색은 **이미 코드에 정의돼 있는 값 그대로** 쓴다(랜드마크는
`towers.json`의 최종 단계 `tint`, 적은 `UITheme.js`의 `VIEW.enemyColors`) — 코드와 다른 색으로
그리면 배치했을 때 어색해진다. 서포터·장애물 4종은 데이터에 색이 정의돼 있지 않아서 이 문서가
기준이다(§3 표에 전부 있음).

## 3. 규격

| 항목 | 값 |
|---|---|
| 파일 형식 | PNG, **투명 배경 필수**(알파 채널) |
| 캔버스 | **정사각형 128×128px** (게임 내 표시는 40px 셀 기준이지만, 여유 있는 해상도로 만들어서
  축소 시 흐려지지 않게 한다) |
| 배치 | 오브젝트를 캔버스 **정중앙**에, 가장자리에서 12~16px 정도 여백을 두고 배치(꽉 채우지 않는다) |
| 배경 | 완전 투명. 흰색/검은색 배경판 없음 |
| 색 | 아래 표의 hex 그대로(그라디언트 금지, 단색 채우기) |
| 스타일 | 플랫 아이콘, 외곽선 없거나 아주 얇게(1px 이하), 그림자·입체 음영 없음 |
| 파일명 | `<카테고리>/<id>.png` — §4 표 그대로. **대소문자까지 정확히 맞출 것**(`GwanghwaMun`처럼
  틀리면 파이프라인이 못 찾는다) |

## 7. 납품 방법 (D6~D7, GitHub 웹)

1. GitHub 웹에서 저장소 열기 → `assets/towers/`(또는 `enemies/`/`supports/`/`obstacles/`) 폴더로 이동
2. "Add file" → "Upload files" → 폰에서 생성한 PNG 선택 → 파일명이 위 표의 `id.png`와 정확히
   같은지 확인 → 커밋(브랜치는 `main` 또는 `feat/ui`, 아무 쪽이나 상관없다 — 정적 파일이라 병합
   충돌이 안 난다)
3. 커밋하면 GitHub Actions가 자동으로 빌드·배포한다(`.github/workflows/deploy.yml`) — 5분 안에
   배포 사이트에 반영된다
4. 확인: 배포 사이트에서 새로고침 후 해당 오브젝트가 도형 대신 이미지로 보이면 성공. 안 보이면
   파일명 오타(대소문자 포함)부터 의심한다
