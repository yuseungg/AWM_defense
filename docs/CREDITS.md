# CREDITS.md — 외부 리소스 출처 기록

공모전 제출물이라 모든 리소스는 **CC0(퍼블릭 도메인)이거나 팀이 직접 제작**한 것이어야 한다.
`assets/`에 파일을 추가할 때마다(사운드든 이미지든) 이 문서에 한 줄씩 기록하는 걸 규칙으로 한다 —
나중에 출처를 못 찾아서 못 쓰게 되는 사고를 막는다.

**규칙: 출처가 불명확하거나 라이선스를 확인 못 한 파일은 절대 커밋하지 않는다.**

## 사운드 (`assets/sounds/`)

`SoundManager.js`(`src/fx/SoundManager.js`)가 읽는 키: `fire`(발사/피격 근사) · `kill`(처치) ·
`warning`(조명 하강 경고) · `levelup`(레벨업) · `gameover`(게임오버) · `bgm`(배경음 1개, 루프).
파일명은 `assets/sounds/<key>.mp3` 형식이어야 코드 수정 없이 반영된다.

|---|---|---|---|---|

프롬프트 요약·날짜를 아래에 기록한다(AI 생성물도 출처 기록 대상 — 어떤 도구·프롬프트로 만들었는지
남겨야 심사 시 설명 가능하다).
