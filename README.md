# 서울 디펜스 (AWM_defense)

웹 브라우저에서 돌아가는 **로그라이트 엔드리스 타워디펜스**.
서울의 실존 랜드마크를 타워로 세워 도시 문제(미세먼지·과속차량·쓰레기더미)가 코어에 도달하는 것을 막는다.

**플레이:** https://yuseungg.github.io/AWM_defense/

---

## 이 게임의 정체성

- **N서울타워 조명 = 체력바.** 숫자 체력바가 없다. 4단계(파랑→초록→노랑→빨강)
- **타워의 공격 = 그 건물의 실제 기능 = 그 도시문제의 실제 해법**
- **성장 3채널 분리** — 드래프트(수평 다양성) / 골드(수직 파워) / 보스 정책(스윙)
- **모든 오브젝트는 실존 서울의 무언가**

## 개발 문서

| 파일 | 내용 |
|---|---|
| `CLAUDE.md` | **프로젝트 계약서.** 코드 쓰기 전에 반드시 읽는다 |
| `GAME_DESIGN.md` | 기획 원본 (읽기 전용) |
| `SETUP.md` | 저장소·배포 셋업 절차 |

## 로컬 실행

```bash
npm install
npm run dev      # http://localhost:5173/AWM_defense/
npm run build    # 배포 빌드 검증
```

## URL 플래그

| 플래그 | 동작 |
|---|---|
| `?debug=1` | 격자 표시 · 웨이브 점프 · 골드/XP 치트 · 배속 해금 |
| `?mock=1` | `MockGameCore`로 실행 (실제 코어 없이 UI 개발) |
